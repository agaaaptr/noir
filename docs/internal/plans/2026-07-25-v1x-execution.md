## 2. Slice S — Intelligent Scaffold

**Spec:** `docs/internal/specs/2026-07-25-slice-s-scaffold-design.md`. **Reuses keystone-K** `core/markers.ts` + `core/block-writer.ts`.

### S-T1 — New `@noir-ai/create` package (engine)
- `packages/create/` with `package.json` (`@noir-ai/create`, MIT, `files:["dist","templates","migrations"]`, `exports` map, tsup build, typecheck — mirror a sibling pkg).
- `src/writers.ts` — three-mode writer generalizing K's `blockWriter`:
  - `regenerate(file, content)` — overwrite (pointers).
  - `managedBlock(file, block, content)` — reuse `writeManagedRegion`/`readManagedBlock` from `@noir-ai/core/block-writer`.
  - `skipIfExists(file, content)` — write once.
- `src/manifest.ts` — declarative artifact table `{ path, mode, host?, content|template }` (single source of truth for what init/create/sync write). Port current `cli/init.ts` + `cli/sync.ts` ad-hoc writes into it.
- `src/templates/` — markdown/yaml/json with hand-rolled `{{var}}` interpolation.
- `src/migrations/` — `<from>-<to>.mjs` declarative upgrade scripts; `src/migrations/index.ts` registry + runner. **Conflict = inline markers** (CI-safe, `--no-input`).
- `src/scaffold-version.ts` — stamp/read `.noir/scaffold-version` (`noir-scaffold=1.0.0`).
- `src/stack-detect.ts` — read-only stack detection (package.json/workspaces/turbo/nx/Cargo/go/pyproject + framework markers); **never assumes**.
- `src/index.ts` — public API: `scaffold({root, mode:'init'|'create'|'sync', opts})`, `runMigrations(root, from, to)`, `detectStack(root)`.
- Tests: three-mode writer (incl. managedBlock idempotency reusing K's tests as regression), manifest expansion, `{{var}}` interpolation, migration runner (inline conflict path), scaffold-version stamp/read, stack-detect (fixture trees).

### S-T2 — CLI refactor + `noir create`
- `cli/init.ts` + `cli/sync.ts` → thin callers of `@noir-ai/create` (preserve all current behavior: `.mcp.json` regenerate, CLAUDE.md context+rules managedBlock, RULES.md/NOIR.md skipIfExists, syncIgnores). Existing init/skills-emit/sync tests = regression gate (must stay green).
- `cli/commands/create.ts` — **new** `noir create [dir]` (greenfield AI-layer only; AI-layer only, no scaffolder chaining per S-OQ1). Bootstraps `.noir/` + thin root pointers in a new/empty dir.
- `noir init --upgrade` — read scaffold-version → run migrations → re-emit regenerate+managedBlock → leave skipIfExists.
- `noir doctor` — extend to report scaffold-version drift.
- No `create-noir-ai` unscoped package this session (name-availability risk; `noir create` + `npx @noir-ai/cli create` suffice). Documented as future.

### S acceptance
- `noir init` produces full AI foundation via manifest (three-mode); idempotent; `--upgrade` runs migrations.
- `noir create <dir>` bootstraps a fresh dir's AI layer (no code generation).
- `.noir/scaffold-version` stamped; `noir doctor` reports drift; stack-detect read-only.
- **Gate:** `pnpm build/lint/typecheck/test` green (746+ tests); new tests for writer/manifest/scaffold-version/migrations; K's blockWriter reused (no duplication); regression tests unchanged.
