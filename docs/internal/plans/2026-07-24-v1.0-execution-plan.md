## 2. Per-slice gate (must pass before next slice)

1. **Plan** — task-decomposed plan at `docs/internal/plans/<date>-sN-<topic>.md`.
2. **Implement** — subagent-driven: implementer + reviewer per task (sonnet); sequential within package (shared files: daemon `server.ts`/`ServerContext`, `core/config.ts`).
3. **Validate** — `pnpm build && pnpm lint && pnpm typecheck && pnpm test` ALL green (run by main loop, real output, evidence before assertion).
4. **Final review** — opus whole-branch review + ≤1 fix wave; re-validate.
5. **Checkpoint** — roadmap/README/CHANGELOG/architecture/`.superpowers/sdd/progress.md` + agentmemory; **local commit** on `develop` (do NOT push).

## 3. Rollback strategy

- Each slice = local commits on `develop`. Irrecoverable validation failure → `git reset`/`revert` to last green slice checkpoint.
- Nothing is pushed (user pushes explicitly). Specs/plans/digest versioned in `docs/` → recoverable.
- Shared mutation points (daemon, config) serialized across slices → no cross-slice conflict.

## 4. MVP v1.0 acceptance criteria (goal-loop target)

1. All packages (10) build + lint + typecheck + test green on ubuntu+macos node 22.
2. **E2E dogfood**: `noir init` → Claude Code connects over MCP → one full SDD task (idea→spec→plan→execute→verify→document) with `context_search` returning relevant project context, `memory_save/recall` persisting across a daemon restart, bounded model producing real spec/plan drafts when a key is set **and** degrading to templates when not.
3. Degraded modes pass: no-provider (S8 null), read-only store (daemon down), no-embedder fallback.
4. No silent paid calls (audit + test).
5. Docs/roadmap/agent-memory in sync; deferred debt + v1.x backlog recorded.

## 5. Risk mitigations

- **Native embedder dep**: unit tests use a deterministic `fakeEmbedFn` (no network/model); real-model integration test **guarded/skip-if-absent** (mirror existing `sqliteVec` skip). Load `@huggingface/transformers` lazily (dynamic `import()`) so non-context commands stay fast and offline.
- **Silent paid calls**: S8 provider-explicit ONLY (never infer from env presence); test asserts zero network when no provider configured.
- **Bundle weight**: transformers.js + onnxruntime-node are runtime deps of `@noir-ai/context` only; never imported by `core`/`cli` startup path except when embedding is invoked.
- **Shared mutation**: serialize slices; one writer to `server.ts`/`ServerContext`/`config.ts` at a time.

## 6. `/goal` loop (no such skill installed)

Implemented as a **TaskList-tracked acceptance-gate loop**: after each slice + at finalization, re-evaluate against §4 criteria; identify gaps; fix; repeat until all pass. Process ends only when MVP criteria are met — not when the build first goes green.
