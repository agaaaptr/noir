- `adapters/src/agents-md.ts` (NEW shared helper, NOT an adapter): `emitAgentsMd(ctx): string` — the universal AGENTS.md content (`@.noir/NOIR.md` + `@.noir/rules/RULES.md` + a 2-line project context). Every adapter composes this for the root AGENTS.md so it's byte-identical across hosts.

- `skills/src/types.ts`: `CompileTarget = HostId`; `compiler.ts`: per-target transform — `cursor` → `.mdc` frontmatter; others verbatim. (Emit-location logic stays in the cli/adapter layer.)
- Tests: registry resolves all 5 + throws on unknown; config enum; CompileTarget cursor transform.

## A — Four adapters (`@noir-ai/adapters`) [OPUS, one agent for consistency]
Implement `agents-md`, `gemini`, `cursor`, `opencode` per the spec's emission-contract table. Each:
- `emitContext` → host context file content (GEMINI.md / AGENTS.md / .cursor/rules/general.mdc).
- `emitRules` → host rules (GEMINI.md/AGENTS.md inline; cursor .mdc).
- `emitMcpConfig` → host MCP JSON (reuse claude shape; the adapter returns the STRING; the cli writes it to `mcpConfigPath`).
- `mcpConfigPath` / `agentsMdPath` / `skillsDir?` → host paths (cursor `.cursor/rules`, `.cursor/mcp.json`; gemini `.gemini/mcp.json`; opencode `opencode.json`; agents-md `.mcp.json`).
- Compose the shared `emitAgentsMd` for the root AGENTS.md (cursor + opencode + agents-md emit it; gemini emits AGENTS.md too; claude keeps CLAUDE.md primary but may also emit AGENTS.md).
- Cursor skill→.mdc transform wired (compileSkill target:'cursor').
- Tests per adapter: emission shapes + paths + an `--host <id>` smoke (deferred to CLI step for end-to-end).
