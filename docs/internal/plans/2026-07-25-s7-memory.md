Slice S7. Spec: `docs/superpowers/specs/2026-07-24-s7-memory-design.md`. Grounding: `.superpowers/sdd/2026-07-24-s6-s9-grounding-digest.md`. Builds on S1 (store), S6 (context: EmbedFn + `fuseRrf` + retriever patterns), S8 (model: `complete()` for consolidation).

## Resolved answers
- Capture: **explicit-save default + opt-in Claude Code hooks template** (host-neutral event schema; user installs; never auto-wired, never silent).
- Taxonomy: **dev-flavored open enum** (pattern/preference/architecture/bug/workflow/fact/decision/lesson; unknown accepted; `lesson` reserved for consolidation output).
- Recall: **reuse S6 hybrid retrieval** (`fuseRrf` from `@noir-ai/context` + store `searchFt`/`knn` with `source:'memory'`) + cheap regex entity-boost; BM25-only fallback when no embedder.
- Consolidation: **append-only, explicit job, provider-gated** — consumes S8 `complete()`; refuses + logs if no provider; emits derived `type:'lesson'` with `provenance:[ids]`; originals unchanged.
- MCP tools: `memory_save` / `memory_recall` / `memory_search` / `memory_sessions` / `memory_forget` (+ `memory_consolidate` conditional on `memory.consolidation.enabled`), gated on `ctx.memory`.

## Architecture
- New package `@noir-ai/memory` (10th). Depends on `@noir-ai/core` + `@noir-ai/store`; imports `fuseRrf` (pure fn) + the `EmbedFn`/`EmbedderConfig` types from `@noir-ai/context`; optional `@noir-ai/model` for consolidation.
- Observations live ON TOP of the store (NO schema migration): `indexDoc({id, source:'memory', content, meta})` + `upsertVec(id, vec, {source:'memory'})` + KV `memory:obs:<id>` (authoritative row) + KV `memory:sessions` (session index). Uses S6's deleteDoc/deleteVec for forget.
- The DAEMON owns the embedder: it resolves the embedder ONCE (via context's `resolveEmbedderConfig` + `createEmbedFn`) and passes the same `EmbedFn` to both the `ContextEngine` and the `MemoryEngine`. So memory takes `{store, embed, ...}` — no embedder duplication.
- `MemoryEngine({store, root, projectId, embed, model?})`: methods `save`, `recall`, `search`, `sessions`, `forget`, `consolidate?`, `status`. Built once per serve lifecycle (mirrors ContextEngine/WorkflowEngine).

## Tasks (lean: one implementer each, self-verifies; main loop validates)
- **t1** Scaffold `@noir-ai/memory` + types. `packages/memory/{package.json,tsup.config.ts,tsconfig.json,src/index.ts,src/types.ts}`. Mirror workflow/context scaffold. Types: `MemoryType` (open enum), `Observation`/`SaveInput`, `MemoryHit`, `SessionInfo`, `MemoryConfig`, `MemoryEngine` interface. Re-export `EmbedFn`/`EmbedderConfig` types from context.
- **t2** Store layer + engine core. `packages/memory/src/{store.ts,engine.ts}`. `save(input)` → chunk content lightly (or store whole obs if small) → `indexDoc({source:'memory'})` + `upsertVec(await embed(content), {source:'memory'})` + KV `memory:obs:<id>` (full row: id/type/content/project/sessionId/ts/importance/concepts/files/source/provenance) + update `memory:sessions`. `get`/`forget` (deleteDoc+deleteVec+KV clear). `sessions()` lists from KV. Single-flight serialize mutating ops (mirror context's pattern).
- **t3** Recall (hybrid). `packages/memory/src/recall.ts`. `search(query,opts)` + `recall(query)`: `store.searchFt(query,{source:'memory'})` + `store.knn(await embed(query),{source:'memory'})` → `fuseRrf` (imported from `@noir-ai/context`) → entity-boost (regex over identifiers/paths in the query, no LLM) → return `MemoryHit[]` (hydrate full row from KV). BM25-only fallback (`degraded:true`) when embedder throws/absent.
- **t4** MCP tools + daemon seam. `packages/daemon/src/{memory-seam.ts,server.ts,stdio.ts,http.ts,index.ts,package.json}`. Register `memory_save`/`memory_recall`/`memory_search`/`memory_sessions`/`memory_forget` (gated `ctx.memory`) via `registerTool`+`textResult`; errors → `{ok:false,degraded:true,error}`. `buildMemoryEngine(store,root,projectId,embed,modelCfg?)` seam mirrors context-seam. Wire into stdio/http alongside context.
- **t5** Consolidation (provider-gated). `packages/memory/src/consolidate.ts`. Explicit `consolidate(opts)` job: gather recent observations of given types → prompt S8 `complete({schema, ...})` to synthesize → on success save a derived `type:'lesson'` observation with `provenance:[ids]`, originals unchanged (append-only). If no provider configured (complete returns null) ⇒ refuse + log (`{ok:false,reason:'no provider configured'}`), NEVER a silent paid call. MCP `memory_consolidate` registered only when `memory.consolidation.enabled`.
- **t6** Config + daemon wiring. `packages/core/src/config.ts` (+ `packages/memory/src/config.ts`). Add `memory:` block to NoirConfigSchema mirroring `daemon:`: `{ consolidation: z.object({ enabled: z.boolean().default(false), provider: z.string().optional(), model: z.string().optional(), types: z.array(z.string()).optional() }).default({ enabled:false }) }`. Daemon: resolve the embedder ONCE (context's resolveEmbedderConfig+createEmbedFn) and pass the same EmbedFn to ContextEngine + MemoryEngine; resolve modelCfg via S8's resolveModelConfig for consolidation.
- **t7** Capture template + power skills. `packages/memory/src/capture.ts` (host-neutral `CaptureEvent` type + a `memory_save`-shaped mapper) + an OPT-IN Claude Code hooks template as a **doc/settings snippet the user installs** (e.g. `packages/memory/templates/claude-hooks.md` or emitted by `noir init` behind a flag) — NEVER auto-wired. Add `noir-recall` + `noir-remember` builtin power skills (light playbooks; WHEN-led).
- **t8** Tests (offline). `packages/memory/test/*.test.ts` + `packages/daemon/test/memory-tools.test.ts`. Use `fakeEmbedFn` (offline): save→recall round-trip; forget removes doc+vec+KV; sessions index; consolidation REFUSES when no provider (returns {ok:false}, no complete() call); consolidation saves a `lesson` with provenance when a fake model is injected; BM25-only degraded recall; entity-boost; MCP round-trip via InMemoryTransport; read-only store keeps recall working.
