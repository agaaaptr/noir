# S1 Stores Implementation Plan (`@noir-ai/store`)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `@noir-ai/store` — embedded SQLite (`better-sqlite3`) + FTS5 (BM25, window snippets) + `sqlite-vec` (384-dim kNN), owned by the daemon as single writer, with a read-only FS-fallback — and surface it via a `noir.store_status` MCP tool.

**Architecture:** One in-process SQLite DB per project at `.noir/store/<projectId>.db` (keyed by canonical `ProjectId`, never a path). `Store` interface (no I/O in types) + `SqliteStore` impl. State KV + FTS5 external-content index + `vec0` vector table. The daemon opens it lazily and is the only writer; the CLI/diagnostic path can open it read-only when the daemon is down (degraded reads).

**Tech Stack:** `better-sqlite3` (engine), `sqlite-vec` (vectors via `sqliteVec.load`), FTS5 (built-in), TypeScript ESM, vitest, Biome, tsup. Vec dimension **384** (MiniLM-L6-v2). Embeddings are **not** generated in S1 — `EmbedFn` is a typed seam S6/S7 injects.

**Spec:** `docs/superpowers/specs/2026-07-23-s1-stores-design.md` (OQ-1…6 resolved).

## Global Constraints

(Copied verbatim from the S1 spec. Every task implicitly includes these.)

- **Engine = `better-sqlite3`** (latest v12+; MIT; prebuilts for linux+macos; N-API for Node 22). API: `new Database(path, opts?)`, `db.pragma()`, `db.exec(sql)`, `db.prepare(sql)` → `.run/.get/.all`, `db.loadExtension(path)`.
- **Vectors = `sqlite-vec`** npm pkg: `import * as sqliteVec from 'sqlite-vec'; sqliteVec.load(db);`. Vectors bound as `Buffer.from(new Float32Array([...]).buffer)` (BLOB). `vec0` virtual table; kNN via `WHERE embedding MATCH ? ORDER BY distance LIMIT k`. If a platform ever lacks the prebuilt binary, gate vec tests (skip + reason).
- **Full-text = FTS5** external-content table (`docs_fts` content_rowid → `docs`); `bm25(docs_fts)` ranking (more negative = more relevant); `snippet(docs_fts, 2, …)` for window-extracted snippets (never truncate). `tokenize='porter unicode61'`.
- **DB location:** `.noir/store/<projectId>.db` (project-local primary). WAL mode (`PRAGMA journal_mode=WAL`). Read-only open via `new Database(path, { readonly: true })` + `PRAGMA query_only=1`.
- **ProjectId keying:** the DB path derives from `ProjectId` (not `root`); add `paths.storeDb(root, projectId)` to `@noir-ai/core`.
- **Single writer:** the daemon opens the store; CLI/hosts reach it via the daemon (MCP). Read-only direct-open is the FS-fallback (degraded reads, no writes).
- **Module = ESM** (`"type":"module"`, relative `.js` imports, NodeNext).
- **Migrations = hand-rolled** versioned SQL: `schema_version` table + ordered migration files; idempotent re-open.
- **Vec dim = 384.** Embeddings injected via `EmbedFn = (text: string) => Promise<Float32Array>` (defined in store, implemented in S6/S7).
- **TDD:** failing test first, watch fail, minimal impl, watch pass, commit.

`packages/store/sql/v1.sql`:
```sql
CREATE TABLE IF NOT EXISTS schema_version (version INTEGER PRIMARY KEY);
CREATE TABLE IF NOT EXISTS kv (key TEXT PRIMARY KEY, value TEXT NOT NULL);
CREATE TABLE IF NOT EXISTS docs (
  id TEXT PRIMARY KEY, source TEXT NOT NULL, content TEXT NOT NULL, meta TEXT
);
CREATE VIRTUAL TABLE IF NOT EXISTS docs_fts USING fts5(
  content, content_rowid='rowid', tokenize='porter unicode61'
);
-- keep docs_fts in sync with docs
CREATE TRIGGER IF NOT EXISTS docs_ai AFTER INSERT ON docs BEGIN
  INSERT INTO docs_fts(rowid, content) VALUES (new.rowid, new.content);
END;
CREATE TRIGGER IF NOT EXISTS docs_ad AFTER DELETE ON docs BEGIN
  INSERT INTO docs_fts(docs_fts, rowid, content) VALUES('delete', old.rowid, old.content);
END;
CREATE TRIGGER IF NOT EXISTS docs_au AFTER UPDATE ON docs BEGIN
  INSERT INTO docs_fts(docs_fts, rowid, content) VALUES('delete', old.rowid, old.content);
  INSERT INTO docs_fts(rowid, content) VALUES (new.rowid, new.content);
END;
CREATE VIRTUAL TABLE IF NOT EXISTS vec USING vec0(embedding float[384], source TEXT, id TEXT);
```

`packages/store/src/migrations.ts`:
```ts
import { readFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { dirname, join } from 'node:path';
import type Database from 'better-sqlite3';

const here = dirname(fileURLToPath(import.meta.url));
// migrations live at packages/store/sql (src-relative at runtime; dist bundles? see note)
const migrations: Array<{ version: number; file: string }> = [{ version: 1, file: 'v1.sql' }];

export function migrate(db: Database.Database): void {
  db.exec('CREATE TABLE IF NOT EXISTS schema_version (version INTEGER PRIMARY KEY);');
  const applied = new Set(db.prepare('SELECT version FROM schema_version').all().map((r: any) => r.version));
  for (const m of migrations) {
    if (applied.has(m.version)) continue;
    const sql = readFileSync(join(here, '..', 'sql', m.file), 'utf8');
    db.exec('BEGIN');
    try { db.exec(sql); db.prepare('INSERT INTO schema_version(version) VALUES (?)').run(m.version); db.exec('COMMIT'); }
    catch (e) { db.exec('ROLLBACK'); throw e; }
  }
}
```
> Note: `sql/v1.sql` must ship in the package + resolve from `dist`. Simplest: have `tsup` copy `sql/*.sql` to `dist/` (`tsup.config.ts` `copy: { items: [{ from: 'sql', to: 'sql' }] }`), and resolve relative to `import.meta.url`. If tsup copy isn't available, inline the v1 SQL as a TS string constant in `migrations.ts` (avoids file-resolution entirely) — implementer's call, keep `sql/v1.sql` as the source of truth either way.

`packages/store/src/sqlite-store.ts`:
```ts
import Database from 'better-sqlite3';
import { mkdirSync } from 'node:fs';
import { paths, type ProjectId } from '@noir-ai/core';
import { migrate } from './migrations.js';
import type { OpenOptions, Store } from './types.js';

export async function openStore(opts: OpenOptions): Promise<Store & { __db: Database.Database }> {
  const dbPath = paths.storeDb(opts.root, opts.projectId);
  mkdirSync(paths.storeDir(opts.root) /* add to core paths: join(root, NOIR_DIR, 'store') */, { recursive: true });
  const db = new Database(dbPath, { readonly: opts.readonly === true });
  db.pragma('journal_mode = WAL');
  if (opts.readonly !== true) migrate(db);
  else { /* read-only: ensure schema exists only if already migrated; do not write */ }
  return { projectId: opts.projectId, __db: db, close: async () => db.close() };
}
```
> Add `paths.storeDir(root)` to core layout alongside `storeDb`. In read-only mode, do NOT run migrations (can't write); if the schema is missing, queries simply fail — acceptable for degraded reads.

```ts
indexDoc(doc) {
  this.__db.prepare('INSERT INTO docs(id, source, content, meta) VALUES(?, ?, ?, ?) ON CONFLICT(id) DO UPDATE SET source=excluded.source, content=excluded.content, meta=excluded.meta')
    .run(doc.id, doc.source, doc.content, doc.meta ? JSON.stringify(doc.meta) : null);
}
searchFt(query, opts) {
  const limit = opts?.limit ?? 10;
  const sql = opts?.source
    ? `SELECT d.id, d.source, d.meta, bm25(docs_fts) AS score, snippet(docs_fts, 0, '<<', '>>', '…', 16) AS snippet
       FROM docs_fts JOIN docs d ON d.rowid = docs_fts.rowid
       WHERE docs_fts MATCH ? AND d.source = ? ORDER BY score LIMIT ?`
    : `SELECT d.id, d.source, d.meta, bm25(docs_fts) AS score, snippet(docs_fts, 0, '<<', '>>', '…', 16) AS snippet
       FROM docs_fts JOIN docs d ON d.rowid = docs_fts.rowid WHERE docs_fts MATCH ? ORDER BY score LIMIT ?`;
  const rows = opts?.source ? this.__db.prepare(sql).all(query, opts.source, limit) : this.__db.prepare(sql).all(query, limit);

}
```

export async function exportMarkdown(db: Database.Database, dir: string): Promise<string[]> {
  const rows = db.prepare('SELECT id, source, content FROM docs').all() as { id: string; source: string; content: string }[];
  const written: string[] = [];
  for (const r of rows) {
